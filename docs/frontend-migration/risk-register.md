- Which actual authentication settings/email routes override the checked-in defaults, and what test accounts/mailbox can validate their transitions?
- Which legacy bugs should receive explicit corrections rather than parity preservation (domain scope, duplicate tags, permission discrepancies and failed-write behavior)?

These are implementation/cutover questions, not missing inventory artifacts. The source inventory, API map, editor/search baseline and ownership decision can be reviewed now. Runtime application code and dependencies were not modified; no browser/API suite was run or claimed to pass.
