# Workflow planner

Open `/workflows/design/` to plan a sequence of bio.tools functions:

1. Choose whether you need a tool that accepts an input or produces an output.
2. Select EDAM data and format terms; optionally select an EDAM operation.
3. Review the matching functions and their exact, related or uncertain evidence.
4. Add functions as steps, connect them and adjust the design.
5. Sign in to save a private draft. Sharing is explicit and can be revoked.

Matching respects which data and formats belong to the same function and input
or output. Missing or obsolete annotations are shown as uncertainty, not as a
confirmed match. Search reads live registry data; changes while paging can alter
results, and the interface offers a fresh search.

Designs can be imported or exported as portable planning descriptions. They are
not executable workflows and cannot be sent to a workflow engine. The existing
`/workflows` gallery displays annotated images separately from the designer.
